# MetamaisKaulins

Salīdzinot manu spēli ar šo piemēru, es šo kauliņu izmantotu spēles sākumā. Manā spēlē kauliņu met pašā sākumā, lai iegūtu punktus turpmākai spēlei. Vienīgais, ko es noņemtu, ir punktu anulēšanas funkcija, jo manā spēlē kauliņus var mest piecas reizes stundā, un, mēģinājuma skaitu jāpapilda, bet neanulē. Es arī mainītu dizainu uz kaut ko spilgtāku vai ar jauku attēlu aizmugurē, un, iegūstot punktus, es pievienotu animāciju un ziņojumu, kas norāda, ka esat nopelnījis noteiktu punktu skaitu.
